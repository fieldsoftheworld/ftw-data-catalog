# Fields 2025 — thinned field polygons (test)

Every 2025 FTW PRUE field polygon (1.58B), z0–13, through tylertoo's
generalization ladder from z0 (density thinning + simplification + tile-size
cap). Layer `fields`, per-field properties: `area` (m²), `confidence` (0–100,
sparse), `country`, `state`. Styles: plain **boundaries** (default), per-field
**confidence**, per-field **size**.

Built pre-dedupe (boundary-straddling fields draw twice) and unfiltered;
superseded by the per-year handover archives once they land. The raw polygons
live in the [vectors collection](../../vectors/collection.json).
